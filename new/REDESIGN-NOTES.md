# Brampton Preservation Trust redesign

This is a drop-in redesign of the existing static website. No build step is required.

## What changed

- Reworked the visual identity into an architectural field-journal style inspired by survey drawings, archive catalogues and the fabric of Brampton Old Church.
- Retained the large seasonal hero and its existing month-based image selection.
- Preserved the site's copy, page structure, downloadable resources, event feed and existing interactive behaviour.
- Added a custom monogram favicon and image-led article heroes with visible photo credits.
- Rebuilt responsive layouts for desktop, tablet and mobile, including an accessible mobile navigation treatment.
- Removed decorative sequence and catalogue numbers in favour of masonry-line and arched-window motifs.
- Corrected the featured resource-card image layering and isolated homepage film styling from the research page.

## Deployment

Upload the contents of this folder to the same GitHub Pages repository or static host, replacing the current site files. The existing `CNAME`, `robots.txt`, `sitemap.xml`, images, PDFs, minutes and JSON data files are included.

The site continues to load Google Fonts and Font Awesome from their public CDNs. All other site assets are included locally.
